     4→KOBİ satış ekipleri için production kalitesinde CRM + ERP süperapp (HubSpot/Zoho KOBİ segmenti hedefi).

     9→## 1. Uygulama Planı
    10→
    11→### Mimari Kararlar (Çevre Adaptasyonları)
    12→- **Framework**: Next.js 16 App Router + TypeScript strict
    13→- **Veritabanı**: Prisma + SQLite (Supabase/Postgres çevrede yok). Multi-tenant izolasyonu `tenant_id` + uygulama seviyesinde RBAC helper'ları ile (RLS yerine app-level enforcement — API + UI katmanlarında).
    14→- **Maps**: Gerçek Google Maps API anahtarı yok → gerçekçi Türk işletme verisi üreten mock Places servisi + z-ai-web-dev-sdk web-search ile zenginleştirme. UI/UX tam production kalitesinde; servis değiştirilebilir.
    15→- **Tek Route**: Çevre kısıtı nedeniyle yalnızca `/` route'u. SPA mimarisi — Zustand store ile görünüm yönetimi, client-side navigation.
    16→- **Auth**: Demo auth (kullanıcı seçimi) — localStorage'da session. NextAuth altyapısı hazır ama demo için basit tutuldu.
    17→- **Para birimi**: TRY varsayılan, çoklu dört desteği (currency alanı).
    18→- **Tarih**: DD.MM.YYYY, saat 24h.
    19→- **Telefon**: E.164 (+90…).
    20→
    21→### Geliştirme Sırası
    22→1. Foundation: Prisma şema + seed + app shell + auth/RBAC + tema + i18n
    23→2. M1: Kimlik/Şirket/Kullanıcı/Rol
    24→3. M2: Müşteri Portföyü + Müşteri 360
    25→4. M3: Google Maps Potansiyel Müşteri Madenciliği
    26→5. M4: Fırsat/Pipeline Kanban
    27→6. M5: Görevler/Hatırlatıcılar/Otomasyon
    28→7. M6: Raporlar/Dashboard
    29→8. Doğrulama (Agent Browser) + cron job

   318→## 4. Varsayımlar
   319→
   320→1. **Auth**: Çevrede gerçek email/smtp olmadığından, demo auth (kullanıcı seçimi ekranı) kullanılacak. 8 demo kullanıcı önceden seed edilecek.
   321→2. **RLS yerine app-level**: SQLite'ta RLS yok. Tüm sorgular `tenantId` + `ownerId`/`managerId` hiyerarşisi ile uygulama seviyesinde filtrelenecek. API route'larında RBAC middleware pattern.
   322→3. **Google Maps**: API anahtarı yok. Mock Places servisi gerçekçi Türk işletme verisi (diş klinikleri, kuaförler, restoranlar vb.) üretecek. Harita görselleştirmesi için statik SVG tabanlı harita mock'u + Leaflet benzeri basit görsel. Servis arayüzü değiştirilebilir şekilde tasarlanacak.
   323→4. **Realtime**: Faz 1'de polling ile; socket.io altyapısı Faz 2 için hazır.
   324→5. **i18n**: Arayüz Türkçe sabit. next-intl yüklü; İngilizce mesaj dosyaları hazırlanacak ama aktive Faz 2.
   325→6. **Dışa aktarma**: ExcelJS yerine CSV üretimi (basit, dependency yok) + JSON. XLSX için sheet kütüphanesi eklenebilir.
   326→7. **Para birimi**: TRY varsayılan. Değerler `Float` saklanır, formatlama katmanında TRY/EUR/USD.
   327→8. **Telefon**: E.164 (+90…). Formatlama helper'ı normalize + display yapacak.
   328→9. **Audit log**: Tüm create/update/delete işlemlerinde before/after JSON.
   329→10. **Faz 2 (ERP-lite)**: Sadece şema (product, stock_movement, quote, quote_line, invoice) hazırlanacak, UI yok.
